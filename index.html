The Journey So Far

Every board tells a story.

Ever since I was three years old, I loved building with LEGO. I enjoyed taking individual pieces and turning them into something bigger, and I always found it satisfying to watch a project come together one step at a time. That feeling has never really changed. Growing up with my dad, an electrical engineer, I saw firsthand what engineering looked like beyond the classroom. Watching him work sparked my curiosity and inspired me to explore electronics for myself. Over time, that curiosity grew into designing PCBs, programming microcontrollers, and learning how hardware and software work together. Today, my favorite part of any project isn't just seeing the finished result, it's watching the entire process unfold. From the first schematic and PCB layout to soldering, programming, and debugging, every stage teaches me something new. This website is where I document that journey, sharing not only the projects I've built, but also the lessons I've learned and the progress I've made along the way.

Featured Project 01

Counter Board

A microcontroller-based button counter PCB designed to read button input, debounce the signal, and increment a displayed count.

Project Type Embedded PCB
Software OrCAD X
Focus Firmware + Hardware
Status Completed

Overview

This project helped me understand how hardware and firmware interact in an embedded system. I designed the PCB, assembled the board, programmed the logic, and debugged issues until the counter worked reliably.

Design Challenges

  • Handling button bounce reliably in firmware
  • Debugging display output problems
  • Understanding bit order and signal behavior
  • Testing the assembled board after soldering

Lessons Learned

  • PCB layout and schematic design
  • Embedded systems debugging
  • How firmware decisions affect hardware behavior
  • The importance of testing small parts of a system

Featured Project 02

Intruder Alarm PCB

A custom intruder alarm board designed to detect input and display a visual alert sequence.

Project Type Security Display PCB
Focus Visual Alert Logic
Output Display Sequence
Status Completed

Overview

This project uses a visual display sequence to represent an intruder alarm state. The carousel shows the display progressing from eyes to warning symbols to an intruder message.

Design Challenges

  • Creating a clear visual alert sequence
  • Organizing the PCB around the display
  • Designing around a real-world use case
  • Making the output easy to understand quickly

Lessons Learned

  • Designing around user feedback
  • Planning visual states for a circuit
  • PCB documentation and presentation
  • Turning a concept into a finished board
